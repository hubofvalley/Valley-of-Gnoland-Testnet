# Sapphire Snapshot Guide

No verified Sapphire snapshot provider is currently configured.

Topaz snapshot archives from UTSA and Hazen are incompatible with `sapphire-1`. Valley of Gnoland intentionally blocks menu option `1c` rather than risk corrupting a Sapphire node.

Use normal peer synchronisation and monitor progress with `1e. Show Node Status`. Snapshot support will return only after a provider publishes a Sapphire-specific archive and its chain identity has been verified.
